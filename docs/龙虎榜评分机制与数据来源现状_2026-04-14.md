# 龙虎榜评分机制与数据来源现状（用于改进）

更新时间：2026-04-14

## 1. 范围与结论速览

本文基于当前代码实现梳理“龙虎榜 AI 评分排名”机制（`LonghubangScoring`），目标是为后续改进提供一份可执行基线。

核心结论：

1. 当前综合评分是**8维加总，满分100分**，并非机器学习模型。
2. 主评分入口在 `longhubang_scoring.py` 的 `score_all_stocks(...)` / `calculate_stock_score(...)`。
3. 评分主数据来自：龙虎榜原始记录 + 4类增强信号（概念主线、连板晋级、同花顺热榜、P1增强）。
4. `kpl_list` 已接入整体分析链路，但**当前不直接参与综合评分加总**（主要用于展示/分析师上下文）。
5. 2026-04-14 已回滚：7日K线趋势与价格区间约束不再参与龙虎榜评分链路。

---

## 2. 评分数据流（从引擎到排名）

在 `LonghubangEngine.run_comprehensive_analysis(...)` 中，阶段3与阶段3.5的评分数据流如下：

1. 先抓取基础龙虎榜数据（并按股票去重保留最近榜单）。
2. 阶段3抓取增强数据：
   - `concept_rotation_data`（概念主线）
   - `limit_step_data`（连板晋级）
   - `ths_hot_data`（同花顺热榜）
   - `kpl_list_data`（开盘啦热度，当前不直接计分）
   - `p1_signal_data`（P1增强信号）
3. 阶段3.5调用 `self.scoring.score_all_stocks(...)` 计算每只股票8维分数与总分，排序后输出排名表。

---

## 3. 综合评分结构（总分100）

当前总分结构：

- 买入资金含金量：0-12
- 净买入额：0-18
- 卖出压力：0-14
- 机构共振：0-15
- 其他加分项：0-14
- 板块轮动：0-15
- 连板晋级：0-2
- 同花顺热榜：0-10

总分 = 上述8项直接相加（未做二次归一化）。

---

## 4. 八个维度的现行计算逻辑

## 4.1 买入资金含金量（0-12）

基础逻辑（基于龙虎榜买方席位）：

- 顶级游资命中：每个 +10（先在旧量纲上累计）
- 知名游资命中：每个 +5
- 其他买方：每个 +1.5
- 旧量纲封顶30，再映射到22分

P1修正（嵌入，不单独加项）：

- 机构买入占比、机构净买入为正 -> 增加 `inst_boost`
- 游资信号分与游资净额为正 -> 增加 `youzi_boost`
- 最终仍封顶22

说明：该维度本质是“席位质量 + 机构确认 + 游资确认”的混合质量分。

## 4.2 净买入额（0-18）

基础逻辑：

- 先统计总净流入（`净流入金额/jlrje`）
- 按金额分段得到旧量纲（0-25），再映射到18分

P1修正（嵌入）：

- 龙虎榜净额是否为正
- 主力净流入（`moneyflow_ths`）是否为正
- 主力净流入正天数占比
- 游资净额是否为正、游资正向占比
- 累计boost上限2.2分，最终封顶18

## 4.3 卖出压力（0-14）

基础逻辑：

- 用 `总卖出 / 总买入` 得到卖出比例
- 比例越低得分越高（先映射到旧量纲0-20，再映射到14）

P1修正（嵌入）：

- 封板质量高、开板少 -> 加分
- 游资负向命中占比高 -> 扣分
- 最终限制在0-14

## 4.4 机构共振（0-15）

基础逻辑：

- 有机构+有游资：15（最高）
- 仅机构：8~12
- 仅游资：5~10

P1修正（嵌入）：

- 机构买入占比高、机构净额为正、游资信号高 -> 额外上调
- 最终封顶15

## 4.5 其他加分项（0-14）

由四个子因子组成：

1. 主力集中度（席位数越少越集中，最高1.4）
2. 热门概念关键词命中（最高1.2）
3. 连续上榜（记录>=3加0.8，=2加0.4）
4. 买卖比优秀（最高0.6）

特征：该项规则偏经验化，且关键词是静态列表。

## 4.6 板块轮动（0-15）

输入：`concept_rotation_data` + `limit_step_data` + 个股概念集合。

计算步骤：

1. 先构造个股“增强概念集”：
   - 优先 `concept_rotation.stock_concept_map`
   - 补充龙虎榜原始概念字段
   - 再补充 `limit_step` 的概念兜底
2. 分别匹配两类强度图谱：
   - `concept_strength_map`（概念主线）
   - `concept_step_strength_map`（连板梯队概念）
3. 对命中结果给分：
   - 主线部分最高约9分（强度分 + 最强概念命中 + TOP3命中 + 多主线命中）
   - 连板梯队部分最高约6.3分（强度分 + 最强命中 + TOP3命中 + 多概念命中）
4. 总体封顶15分

## 4.7 连板晋级（0-2）

- 直接读取 `limit_step_data.stock_step_heat_map[code].score`
- 该score在热度抓取器里已按规则计算并限制在0-2

## 4.8 同花顺热榜（0-10）

- 直接读取 `ths_hot_data.stock_hot_map[code].score`（0-1）
- 线性放大为 0-10

`stock_hot_map.score`由两部分构成：

- 名次映射（TOP10=0.8、TOP30=0.6、TOP50=0.45、TOP100=0.3、其余0.15）
- 连续在榜天数加成（上限0.2）

## 5. 评分使用了哪些数据（按来源汇总）

## 5.1 直接来自龙虎榜原始数据（本地聚合）

字段/信息：

- 股票代码、名称
- 买入金额、卖出金额、净流入金额
- 游资名称、营业部
- 概念字段
- 单股多条席位记录

用途：4个主资金维度 + bonus的主要输入。

## 5.2 Tushare 概念主线链路（板块轮动维度核心）

优先级：

1. `dc_member + dc_index`
2. 回退 `dc_concept_cons`
3. 再回退 `kpl_concept_cons`

并补充 `dc_concept` 快照用于概念热度/白名单过滤。

产出关键结构：

- `stock_concept_map`：个股 -> 概念列表
- `concept_strength_map`：概念 -> 强度(0~4)
- `strongest_today` / `daily_rankings`

用途：板块轮动评分。

## 5.3 Tushare 连板晋级链路

接口：`limit_step`

产出关键结构：

- `stock_step_heat_map[code].score`（0~2）
- `concept_step_strength_map`（概念梯队强度，归一到0~4）
- `strongest_step_concepts`

用途：

- 连板晋级维度（0~2）
- 板块轮动维度（作为“梯队概念匹配”子图谱）

## 5.4 Tushare 同花顺热榜链路

接口：`ths_hot`（A股热股）

产出关键结构：

- `stock_hot_map[code].score`（0~1）
- `best_rank/latest_rank/appear_days`

用途：同花顺热榜维度（0~10）。

## 5.5 Tushare P1增强链路（用于修正四个资金维度）

接口组：

- 龙虎榜统计/机构：`top_list` + `top_inst`
- 游资画像：`hm_list` + `hm_detail`
- 资金确认：`moneyflow_ths` + `moneyflow_cnt_ths` + `moneyflow_ind_ths`
- 封板质量：`limit_list_ths` + `limit_list_d`

产出关键结构：

- `stock_signal_map[code]`：
  - `lhb_signal_score`
  - `money_signal_score`
  - `limit_quality_score`
  - `youzi_signal_score`
  - 机构净额/占比、主力净流、游资净额、开板次数、封板质量等

用途：

- 不直接作为第9项加分
- 通过 `LonghubangScoring` 内部逻辑，**嵌入修正**：
  - 资金含金量
  - 净买入额
  - 卖出压力
  - 机构共振

## 5.6 已接入但当前未直接参与综合评分的数据

- `kpl_list`（开盘啦热度）当前主要用于：
  - UI“概念主线/题材热度”展示
  - AI分析师上下文

即：它影响“分析解释层”，但不直接进入综合评分8维加总。

## 6. 当前评分结果输出字段

评分表除了8个维度和总分，还输出了辅助解释字段：

- `主线匹配`（匹配到的主线/梯队概念）
- `连板高度`、`热榜最佳`
- `P1增强`、`机构净额`、`主力净流`、`封板质量`、`游资信号`、`游资画像`

这些字段用于解释分数来源，但当前总分仍是固定规则加总。

## 7. 现机制的优点与限制（为改进准备）

## 7.1 优点

1. 结构清晰，可解释性强（每项都有可追溯来源）。
2. 数据降级策略完整（接口不可用时可继续运行）。
3. 兼顾了“席位行为 + 主力资金 + 板块主线 + 热榜热度”。
4. P1增强将多源信息回注到核心资金维度，避免“仅看龙虎榜当日静态数据”。

## 7.2 主要限制

1. **量纲混合但权重固定**：不同市场状态（抱团/轮动/退潮）下，固定权重可能失真。
2. **部分阈值经验化较强**：例如分段阈值、关键词加分、top名单，维护成本高。
3. **多源高度相关风险**：资金类指标间可能重复计分（如净流入与主力净流正反馈）。
4. **时序信息压缩**：目前按近几日聚合，未显式建模“加速/衰减拐点”。
5. **概念匹配依赖字符串包含**：同义词、歧义词、噪音词仍可能影响命中质量。
6. **kpl_list未入总分**：前端强调的开盘啦题材热度与综合评分存在“认知断层”。

---

## 8. 改进建议（按优先级）

## P0（建议优先）

1. **做状态化权重**：按市场状态切换权重模板（高标抱团/题材轮动/弱市防守）。
2. **去重与正交化**：对资金类因子做相关性约束，避免重复加分。
3. **引入置信度分**：接口缺失或覆盖率低时，输出`score_confidence`并约束推荐阈值。

## P1（次优先）

4. **统一概念语义层**：建立概念别名词典与标准概念ID，减少字符串匹配误差。
5. **把kpl_list纳入评分**（可作为板块轮动子项或独立0~5分），与前端叙事一致。
6. **分位数替代硬阈值**：净流入、封板质量等从固定阈值改为滚动分位评分。

## P2（增强项）

7. **增加回测评估框架**：按T+1/T+3收益、最大回撤评估每个因子边际贡献。
8. **输出因子贡献解释**：例如SHAP风格或“每维度贡献条”，支持策略迭代复盘。
9. **版本化评分规则**：给每次规则升级打`score_version`，便于报告可比与AB对照。

## 9. 可直接落地的改造切入点（代码层）

1. `longhubang_scoring.py`
   - 抽离权重与阈值到配置对象（便于状态化和AB测试）。
   - 将P1修正改为标准化增量函数，避免维度间重复覆盖。
2. `longhubang_limit_concept.py`
   - 概念归一层（别名映射 + 噪音屏蔽）前置到统一入口。
3. `longhubang_hot_signals.py`
   - 为`kpl_list`输出与`ths_hot`一致的标准热度评分接口，便于统一入模。
4. `longhubang_engine.py`
   - 增加`score_confidence`与`score_version`注入报告结构。

---

## 10. 一句话总结

当前龙虎榜评分体系已具备“可解释、可运行、多源融合”的工程基础，但下一阶段改进重点应从“规则堆叠”转向“状态化权重 + 因子正交 + 置信度管理 + 可验证回测”。
